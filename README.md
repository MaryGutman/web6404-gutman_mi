# Лабораторная работа №2

## Тема: Многостраничный фан-сайт группы Nirvana

### Состав проекта
- 3 HTML-страницы: `index.html`, `music.html`, `history.html`
- Отдельный файл стилей: `style.css`
- Папка `images/` с 4 картинками

### Страницы
- `index.html` — главная: о группе, состав, фото
- `music.html` — дискография (таблица + описания Bleach, Nevermind, In Utero)
- `history.html` — хронология ключевых событий группы

### Что реализовано
- Блочные и строчные элементы, ссылки, картинки
- Таблица с выравниванием по левому краю, центру и правому краю
- Отдельный CSS-файл, 5 видов селекторов, использование цвета

### Запуск
Открыть `lab2/index.html` в браузере.
