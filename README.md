# Лабораторная работа №3

## Тема: Изучение основ JavaScript.

### Что реализовано:
10 функций на JavaScript.  Все функции успешно проходят автотесты (16 passing).
- `isInteger` — проверка, является ли число целым.
- `even` — возврат массива четных чисел от 2 до 20.
- `sumTo` — сумма чисел до заданного с помощью цикла.
- `recSumTo` — сумма чисел до заданного с помощью рекурсии.
- `factorial` — вычисление факториала числа.
- `isBinary` — проверка, является ли число степенью двойки.
- `fibonacci` — нахождение N-го числа Фибоначчи.
- `getOperationFn` — функция, применяющая переданную операцию и сохраняющая состояние.
- `sequence` — создание генератора арифметической последовательности.
- `deepEqual` — глубокое рекурсивное сравнение объектов и массивов.

### Структура проекта:
- **`src/`** — папка с исходным кодом:
  - `core.js` — файл с реализацией всех функций.
  - `core.spec.js` — файл с автотестами.
- **`package.json`** — конфигурационный файл Node.js (содержит скрипты запуска и зависимости).
- **`package-lock.json`** — фиксирует точные версии установленных библиотек.
- **`.gitignore`** — указывает Git, какие файлы не нужно загружать в репозиторий (например, `node_modules`).
- **`.prettierrc`** — настройки форматирования кода (Prettier).
- **`.prettierignore`** — файлы, которые Prettier должен игнорировать.
